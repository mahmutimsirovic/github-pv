# GitHub Profile Viewer

A simple web app that fetches and displays GitHub user profiles and repositories using the GitHub REST API.  
Built with **HTML, CSS, JavaScript, Node.js, and Express**, with secure API key handling via dotenv.

---

## 🚀 Features
- Search for any GitHub username
- Display profile info (avatar, bio, followers, following)
- List repositories with stars and links
- Responsive UI with polished design
- Secure API token management
